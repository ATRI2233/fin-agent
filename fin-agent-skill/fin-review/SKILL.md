# 周度复盘 Skill

用户说"本周总结""看看准确率""回顾一下"时触发。这是记忆系统的维护入口。

**规则：以下 4 步全部执行，缺一步都看不到完整的准确率分析。**

## 工具调用流程

全部调用，experience_summary 是主角：

### 第一步：拉取历史记录
- `memory_recall` — 拉取本周（或指定时间范围）所有标的的判断记录，包括方向、置信度、准确性。

### 第二步：校验一致性
- `consistency_check` — 对每个标的批量检查：有没有频繁翻转？翻转时有没有合理解释？标记异常标的。

### 第三步：经验学习（主角）
- `experience_summary` — 自动将历史判断与实际走势对比，逐笔验证命中率。更新各信号源（技术面/基本面/情绪/宏观）的准确率权重。过时规则自动淘汰，提炼新的经验规则。

### 第四步：保存元数据
- `rule_manage` — 保存本周总结的元数据（命中率/更新后的权重/新提炼的规则），供下次周度复盘对比。

## 输出要求

- 本周总命中率 + 对比上周趋势
- 各标的命中/失误明细
- 信号源准确率排名（哪个信号来源最可靠）
- 盈亏比统计（平均盈利/平均亏损）
- 新提炼/淘汰的经验规则
- 下周关注标的和建议调整
