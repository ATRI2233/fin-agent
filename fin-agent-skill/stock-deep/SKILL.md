# 个股深度 Skill

用户点名分析某只股票时触发，回答"分析 AAPL""TSLA 怎么样"。

**规则：以下步骤必须全部执行，每调完一步就做下一步。即使某步工具失败（如 sec_filings 超时），也要继续执行后续步骤，不要中途输出结果。全部步骤完成后再综合输出。**

## 工具调用流程

### 第一步：查历史记忆（必须调用）
- `memory_recall` — 参数 `symbol: "<股票代码>"`，查上次分析这只票时的判断（方向、置信度、关键价位）。

### 第二步：技术面（必须调用）
- `technical_levels` — RSI / MACD / 布林带 / 枢轴点 (S1-S3/R1-R3) / 均线系统 (MA5-250)

### 第三步：基本面（必须调用）
- `fundamental_scan` — P/E / ROE / 负债率 / 营收增长率
- `sec_filings` — 最新财报数据（失败则跳过，继续下一步）

### 第四步：新闻与情绪（必须调用）
- `news_sentiment` — 该股的新闻情绪，不调用的话你无法判断情绪面

### 第五步：聪明钱视角（必须调用）
- `options_greeks` — 期权市场隐含方向
- `analyst_ratings` — 华尔街评级和目标价
- `insider_trading` — 内部人在买还是卖

### 第五步续：机构资金流向
使用 risk-mcp 的 `institutional_flow` 获取 13F 数据：
- 前十大机构持有者排名
- 各机构持仓市值、占比、环比变化
- 总流通股趋势（季度）

注意：13F 数据有 45 天延迟，仅反映季度末持仓，不披露空头和衍生品。

### 第六步：风控检查
使用 risk-mcp 的 `risk_gauge`（自动拉取 yfinance 数据计算）：
- 20日/60日年化波动率
- 距52周高点回撤百分比
- 95% VaR（单日最大预期亏损）
注意：risk-mcp 的版本会自动下载数据，无需事先准备价格参数。

若波动率 > 40% 或回撤 > 20%，标记风险警告。

### 第六步续：仓位参考
使用 risk-mcp 的 `position_sizing` 输出凯利公式建议仓位：
- 基于历史收益率和波动率的凯利仓位
- 波动率目标仓位（目标年化波动 20%）
- 综合建议仓位等级（重仓/中等/轻仓/观察仓）
可传入 `expected_return` 覆盖历史预期收益率。

### 第七步：财报日历（可选）
使用 earnings_calendar 检查标的未来 7 日内是否有财报发布。
若有：标注日期、EPS 预期对比、财报敏感期标记。

### 第八步：信号融合与校验（必须调用）
- `signal_fusion` — 多信号加权融合（输入上 5 步的所有数据）
- `consistency_check` — 本次判断 vs 历史判断，方向翻转必须说明原因

### 第九步：输出（自动记录）
- 综合所有数据输出分析报告（自动保存到记忆系统）

## 输出要求

- 综合评分和方向判断
- 技术面关键价位 + 操作建议
- 基本面和财报亮点/雷点
- 聪明钱信号（期权 + 分析师 + 内部交易）
- 与上次判断的一致性对比（有翻转说明原因）

**检查：输出前确认上面所有步骤没有遗漏。漏了则补调再输出。**
