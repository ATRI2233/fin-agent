# 大盘快报 Skill

快速扫描市场全局，回答"今天怎么样""大盘如何"一类的日常问题。

**规则：以下步骤必须全部执行。别跳过 news_sentiment — 不看新闻你解释不了涨跌原因。**

## 工具调用流程

### 第一步：查昨天的判断
- `memory_recall` — 参数 `symbol: "SPX"`（或上次分析的基准指数），查最近一次大盘判断的方向和置信度。这是你比较"今天 vs 昨天"的基准。

### 第二步：大盘与板块
- `market_snapshot` — 主要指数（纳斯达克/标普500/道琼斯/VIX）+ 板块表现
- `sector_rotation` — 11个GICS板块相对强度，发现资金轮动方向

### 第三步：新闻情绪
- `news_sentiment` — 不调用这个，你解释不了市场为什么涨跌。实时新闻 + 时间衰减 + 来源可信度。重点关注：是否有极端新闻在做空信号。

### 第四步：情绪与宏观
- `fear_greed_index` — 市场情绪温度计，含30天历史趋势
- `commodity_prices` — 原油/黄金/天然气，宏观通胀背景

### 第四步续：宏观利率锚定
使用 fred-mcp 获取 FRED 数据：
- `fred_series` — DGS10（10年期国债收益率）、DGS2（2年期）
- `fred_series` — T10Y2Y（期限利差，负值=衰退预警）
- `fred_series` — CPIAUCSL（CPI同比）、UNRATE（失业率）、FEDFUNDS（联邦基金利率）

宏观判断规则：
- 期限利差 < 0 → 衰退风险高，降低看多权重
- CPI 同比 > 4% → 高通胀，加息风险
- 失业率上升 > 0.5% → 经济放缓

### 第五步：保存判断
- `memory_recall` — 存入本次大盘判断（方向/置信度/关键理由），下次调用会读到。（现在是自动记录）

## 输出要求

给用户一份简洁的早报格式：
- 各指数涨跌 + VIX
- 板块轮动方向（谁最强/谁最弱）
- 市场情绪（恐惧贪婪数值 + 趋势）
- 关键新闻驱动因素
- 今日判断（看多/看空/中性 + 置信度 + 理由）
- 与昨日判断的差异（如果有变化要解释原因）
