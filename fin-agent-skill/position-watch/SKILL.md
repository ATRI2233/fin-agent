# 持仓盯盘 Skill

用户说"看看我的持仓""盯盘""检查仓位""关注 XXX"时触发。这是持仓/关注池的持续跟踪入口。

**核心理念：不重复分析老数据，聚焦变化。**

- 刚发生的新闻比一周前的新闻重要
- 技术位突破比横盘重要
- 内部人买卖变化比绝对值重要
- 和上次判断的偏差比重复确认重要

**规则：以下步骤全部执行。如果传入了多个标的，每个标的都跑完再综合输出。工具失败则跳过该标的继续。**

---

## 工具调用流程

### 第一步：确认目标与历史记忆

先查持仓/关注列表，再拉取历史判断记录。

- `memory_recall` — 参数 `key: "portfolio"`，查之前保存的持仓/关注列表。如果没有则用用户本次传入的标的。
- `memory_recall` — 对每个标的查最近一次判断（方向/置信度/关键价位/止损位）。
- 这一步输出：持仓列表 + 每个标的的历史基准。

### 第二步：大盘环境检查

快速确认宏观环境是否有利。不用太详细，够用就行。

- `market_snapshot` — 主要指数涨跌 + VIX（看整体风偏）
- 使用 fred-mcp 的 `fred_series` — DGS10（10年国债收益率）+ T10Y2Y（期限利差）

宏观过滤规则：
- VIX > 30 → 系统性风险高，减仓信号
- T10Y2Y < 0 且加深 → 衰退预警，降低高 Beta 仓位
- DGS10 快速上升 → 成长股估值受压

### 第三步：逐个标的检查

对每个标的执行以下子步骤。**重点看变化，不看绝对值。**

#### 3a 技术面状态
- `technical_levels` — 当前价格在什么位置？
  - 是否突破/跌破关键均线（MA5/MA20/MA60）？
  - 是否接近枢轴点支撑/阻力？
  - RSI 是否进入超买/超卖区域？
  - 与上次分析时的价格对比：涨了/跌了/横盘？

#### 3b 新消息与情绪
- `news_sentiment` — 最近 24-48 小时的最新新闻
  - 是否有影响基本面的重大新闻？
  - 情绪相比上次变好还是变差？
  - **旧新闻（>3天）降权处理，不看过期消息。**

#### 3c 聪明钱动向
- `insider_trading` — 上次检查后有新的内部人交易吗？（比绝对值重要）
- `options_greeks` — 期权市场隐含波动率和方向变化
- 使用 risk-mcp 的 `institutional_flow` — 13F 持仓变化（季度数据，慢信号）

#### 3d 风控与仓位
- 使用 risk-mcp 的 `risk_gauge` — 当前波动率/回撤/VaR 与上次对比
- 使用 risk-mcp 的 `position_sizing` — 当前是否还适合持仓/加仓/减仓

### 第四步：信号融合与一致性校验

- `signal_fusion` — 每个标的的独立信号融合（只传该标的的数据）
- `consistency_check` — **关键步骤**：这次判断 vs 上次判断
  - 方向翻转？→ 必须找出原因（新消息？技术面破位？）
  - 上次止损位被触发？→ 是否已经执行止损？
  - 置信度变化？→ 升高还是降低？

### 第五步：综合输出与操盘建议

给用户的输出格式：

```
📊 持仓检查报告

【大盘环境】
- 指数: S&P 500 +1.2% | VIX 15.2 | 10Y 4.25%
- 宏观判断: 中性偏多（期限利差收窄，风险偏好回升）

【标的1: AAPL】
- 上次判断: 看多 (70%置信度, 入场168, 止损155)
- 当前价格: 175.3 (+4.3% vs 入场)
- 技术面: 站稳 MA20 向上，RSI 62（中性偏多）
- 新消息: 正面上（财报超预期），情绪从上次中性→积极
- 内部人: 过去7天无交易，中性
- 风控: 波动率22%(正常)，VaR 2.8%(正常)
- 一致性: 维持看多，置信度提升至80%
- 建议: ✅ 持有。若突破 178 可加仓，跌破 168 减仓

【标的2: TSLA】
- 上次判断: 看多 (65%置信度)
- 当前价格: 245.0 (-8% vs 入场)
- 技术面: 跌破 MA60，RSI 38（偏弱）
- 新消息: 负面（交付量不及预期）
- 建议: ⚠️ 减仓至半仓。跌破 230 全部离场

【仓位总览】
- 总持仓: 2 只
- 建议加仓: 0 | 持有: 1 | 减仓: 1 | 离场: 0
```

### 第六步：保存记忆

分析完成后，自动记忆系统会记录判断。额外保存：
- 更新 `portfolio` 的持仓列表（如有变动）
- 记录本次检查日期和各标的后续关键价位/止损位
- 下次 `memory_recall` 时能读到完整的持仓跟踪历史
