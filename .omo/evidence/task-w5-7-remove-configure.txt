Task W5-7: Remove configure() module-level functions
=====================================================
Date: 2026-06-09
Branch: phase2-refactor

## Summary

Removed the pre-DI `configure()` pattern from `data_maintenance` module by refactoring
`DataMaintenanceService` to use constructor injection instead of module-level globals.

## configure() functions found

| File | Line | Status |
|------|------|--------|
| main/framework/core/container.py:165 | DI bootstrap | PRESERVED (required) |
| main/data_maintenance/core/data_maintenance.py:25 | Pre-DI wiring | REMOVED + refactored |

## Changes made

### 1. main/data_maintenance/core/data_maintenance.py
- Removed module-level globals: `_dispatcher = None`, `_scheduler = None`
- Removed `configure(dispatcher, scheduler)` function
- Added `__init__(self, dispatcher=None, scheduler=None)` to `DataMaintenanceService`
- Converted all `@staticmethod` methods to instance methods (added `self`)
- Changed `_dispatcher` → `self._dispatcher`, `_scheduler` → `self._scheduler`
- Added `from functools import partial` import
- Updated `_run_task_job()` to accept `service` parameter instead of using class-level static call
- Updated `sync_scheduled_tasks()` to use `partial(_run_task_job, self)` for APScheduler

### 2. main/framework/main.py
- Removed `from main.data_maintenance.core.data_maintenance import configure as configure_maintenance`
- Replaced `configure_maintenance(container.dispatcher, scheduler._scheduler)` with:
  ```python
  maintenance_service = DataMaintenanceService(
      dispatcher=container.dispatcher,
      scheduler=scheduler._scheduler,
  )
  app.state.maintenance_service = maintenance_service
  maintenance_service.sync_scheduled_tasks()
  ```

### 3. main/data_maintenance/api/data_maintenance.py
- Added FastAPI dependency `_get_service(request)` that resolves from `request.app.state.maintenance_service`
- All endpoints now use `svc: DataMaintenanceService = Depends(_get_service)` instead of static calls
- Removed direct import of `DataMaintenanceService` class for static usage
