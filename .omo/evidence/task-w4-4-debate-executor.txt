## 4. DebateNodeExecutor Contract

- Inherits from base.NodeExecutor.
- __init__(self, dispatcher=None) -> forwards dispatcher to base.
- async execute(self, ctx) -> NodeResult:
    * _build_enriched_prompt(ctx) substitutes {param}, {node_field} placeholders
      from ctx.params and ctx.node, then appends predecessor outputs as a
      structured "Upstream Outputs" block (or fills a {upstream} placeholder
      if present in the template).
    * node_with_prompt = {**ctx.node, "prompt": enriched_prompt}
    * debate_output = await DebateExecutor(self.dispatcher).execute_debate(node_with_prompt)
      (DebateExecutor.execute_debate is async in the existing class, so we
      `await` it directly — calling it via asyncio.to_thread would not work
      on a coroutine and the engine itself awaits it inline at line 342.)
    * Returns NodeResult(result={"debate_output": debate_output},
                         output=debate_output)
