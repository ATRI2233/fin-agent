================================================================================
DESIGN NOTES
================================================================================

Dependency decoupling
---------------------
The service uses @runtime_checkable Protocols for its three collaborators
(ExecutionServiceProtocol, NodeExecutorRegistryProtocol, WorkflowRepositoryProtocol).
This was necessary because W4.6 (registry) and W4.9 (execution service) were
being built in parallel by other agents. The Protocols are structural, so the
eventual concrete classes satisfy them without explicit inheritance.

The actual signatures implemented by the parallel agents were discovered and
matched:
  - ExecutionService.create_execution_for_workflow(workflow, params, db) -> WorkflowExecution
    (takes the loaded workflow object, returns a WorkflowExecution with .id)
  - ExecutionService.mark_downstream_skipped(node_id, edges, db) -> list[str]
  - NodeExecutorRegistry.get(node_type) -> NodeExecutor

Per-execution state
-------------------
The service is a singleton (per spec: "Singleton that creates per-execution
contexts"). Every call to run() invokes _reset_execution_state() which clears
_results, _failed_nodes, _skipped_nodes, _chain_sessions, _node_levels, nodes,
edges. This matches the engine's "one WorkflowEngine instance per execution"
contract.

Edge attachment for executors
-----------------------------
NodeContext (base.py dataclass) does not declare an ``edges`` field, but the
AgentNodeExecutor reads it via ``getattr(ctx, "edges", [])`` to support
serial-chain session reuse. The service attaches the workflow edges onto the
context as a non-dataclass attribute before invoking the executor, preserving
the engine's existing behaviour.

Forward reference
-----------------
WorkflowEngine is imported under TYPE_CHECKING to avoid a circular import
during the W4.11 transitional period where both classes coexist.

Module docstring
----------------
"WorkflowService — DAG orchestration. Replaces the outer loop of
WorkflowEngine.execute(). Singleton that creates per-execution contexts."
