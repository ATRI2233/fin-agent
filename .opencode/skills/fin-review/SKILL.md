# 周度复盘 Skill

> **阻断规则：此skill已加载。以下4步必须全部执行。特别是第二步 consistency_check 和第三步 experience_summary 不可省略——前者检测频繁翻转，后者是核心复盘引擎。**

用户说"本周总结""看看准确率""回顾一下"时触发。这是记忆系统的核心维护入口。

---

## 工具调用流程

### 第一步：拉取历史记录
- `memory_recall` — 拉取本周（或指定时间范围）所有标的的判断记录，包括方向、置信度、准确性。

---

### ⛔ 第二步：校验一致性（必须调用 consistency_check 工具）

- `consistency_check` — 对每个标的批量检查一致性。**必须调用工具，不能只靠手动计算。**

#### 频繁翻转检测
| 规则 | 量化标准 |
|------|---------|
| 时间窗口 | 72 小时内同一标的信号翻转 ≥ 2 次 → 触发频繁翻转警告 |
| 置信度惩罚 | 连续翻转后，新信号置信度 × 0.7 |
| 强制冷却 | 触发频繁翻转后，24h 内禁止该标的的新开仓建议 |
| 异常标记 | 被标记的标的在报告中单独列出，标注翻转次数和原因 |

#### 一致性评分
对每个标的计算：
- **一致率** = 本周判断与实际走势一致次数 / 本周总判断次数
- **置信度衰减率** = 平均置信度 vs 上周平均置信度（若下降过多需检查信号源）
- **规则命中率** = 有明确规则支撑的判断 / 总判断数（衡量是否过度依赖直觉）

---

### ⛔ 第三步：经验学习（必须调用 experience_summary 工具）

- `experience_summary` — 自动将历史判断与实际走势对比，逐笔验证命中率。更新各信号源（技术面/基本面/情绪/宏观）的准确率权重。过时规则自动淘汰，提炼新的经验规则。

#### 双维度复盘

**维度一：按标的维度**
- 各标的的命中率 / 盈亏比
- 命中率 < 45% → 观察名单

**维度二：按信号源维度**（进阶复盘）
- 各信号源本周表现：如 MACD金叉、RSI超卖、公告利好 等细分信号分开统计
- 计算各信号源的夏普比/胜率
- 权重更新规则：
  - 信号源权重 = 该信号源历史命中率 × 0.7 + 最新命中率 × 0.3（指数加权）
  - 权重变化 > 10% → 在周报中重点标注，说明原因
  - 命中率 < 45% 的信号源 → 标记为"观察名单"，降低依赖

#### 规则淘汰规则
- 规则连续失误 ≥ 3 次 → 自动移出有效规则库
- 规则命中率 < 40% → 建议重新审视或淘汰
- 新规则提取条件：有明确逻辑 + 历史支撑 + 命中率 > 55%

---

### 第四步：保存元数据
- `rule_manage` — 保存本周总结的元数据：
  - 命中率 / 盈亏比 / 信号源排名
  - 更新后的各信号源权重
  - 新提炼的规则（加入规则库）
  - 淘汰的规则（移出规则库）
  - 下周关注标的

---

## 输出要求

- 本周总命中率 + 对比上周趋势
- 各标的命中/失误明细（含异常翻转标的）
- **信号源准确率排名**（哪个信号来源最可靠）
- 盈亏比统计（平均盈利/平均亏损）
- 新提炼/淘汰的经验规则
- 权重变化明细（变化 > 10% 的信号源重点标注）
- 下周关注标的和建议调整

---

## 量化指标汇总

| 指标 | 公式 | 阈值 |
|------|------|------|
| 频繁翻转 | 72h 内翻转 ≥ 2 次 | 触发警告 |
| 置信度惩罚 | 新置信度 × 0.7 | 连续翻转后 |
| 冷却期 | 触发后 24h 禁止新开仓 | 自动生效 |
| 信号源权重变化 | Δw > 10% | 重点标注 |
| 命中率淘汰线 | < 45% | 观察名单 |
| 规则淘汰线 | 连续失误 ≥ 3 或命中率 < 40% | 自动移出 |
