# 金融分析 Agent Skill

## 核心能力

### 每日市场扫描
- 主要指数快照（纳斯达克/标普500/道琼斯）
- 板块轮动分析（11个GICS板块相对强度）
- 资金流向检测

### 多信号融合分析
- 技术面信号（40%权重）：MA系统/RSI/MACD/布林带/量价
- 基本面信号（35%权重）：财报/估值/盈利质量/成长性
- **新闻情绪（≤15%硬上限）**：建议调 `news_sentiment` 获取实时新闻情绪 — 补充而非替代 signal_fusion
- **财报文件（基本面输入）**：建议调 `sec_filings` 获取最新财报数据 — 增强基本面判断深度
- 宏观环境（10%权重）：大盘走势/利率环境

### 逻辑一致性引擎
- 每次判断与历史对比
- 方向翻转强制解释
- 震荡模式检测与警告
- 置信度稳定性监控

### 经验学习系统
- **分析前**：`memory_recall` 查询该标的历史判断记录，避免重复分析
- **分析后**：`memory_recall` — 自动记录本次判断（方向、置信度、关键价位）
- **定期**：`experience_summary` 自动验证历史判断准确率，提炼经验规则
- 信号源准确率追踪，过时规则自动淘汰

### 技术位计算
- 枢轴点支撑/阻力（S1-S3/R1-R3）
- 移动均线系统（MA5-250）
- RSI/MACD/布林带指标
- 关键价位标注与操作建议

## 分析流程

每次分析按以下顺序调用工具，其中 `news_sentiment` 和 `sec_filings` 为可选补充 — 如果已有足够数据判断可跳过，但建议至少调用一次：

### 第一步：大盘与板块快照
- `market_snapshot` — 指数行情 + 板块表现
- `sector_rotation` — 板块相对强度计算

### 第二步：技术面分析
- `technical_levels` — RSI/MACD/布林带/均线/枢轴点

### 第三步：新闻与财报（可选，建议补充）
- `news_sentiment` — 获取实时新闻情绪，包含时间衰减与极端降权
- `sec_filings` — 获取最新 SEC 财报文件，提取基本面数据

### 第四步：情绪与宏观
- `fear_greed_index` — 恐惧贪婪指数
- `commodity_prices` — 大宗商品（原油/黄金/天然气）

### 第五步：信号融合与校验
- `signal_fusion` — 多信号加权融合评分
- `consistency_check` — 与历史判断对比，检测翻转

### 第六步：记忆与经验（分析前后调用）
- **分析前**（第一步之前）：`memory_recall` — 查询该标的历史判断记录，了解之前的方向和置信度
- **分析后**（所有工具完成后）：自动记录 — 通过自动记录中间件完成
- **收尾**：`experience_summary` — 自动验证历史判断准确率，更新信号源权重

## 使用方式

### 每日分析
```
fin-agent daily
```
执行完整每日分析流程：**查询历史** → 市场快照 → 板块轮动 → 技术面 → 新闻 → 财报 → 情绪与大宗商品 → 信号融合 → 一致性校验 → **保存判断** → **经验学习**

### 每周总结
```
fin-agent weekly
```
`memory_recall` 回顾本周判断 → `experience_summary` 提炼经验规则 → `rule_manage` 保存更新后的权重

### 个股分析
```
fin-agent analyze AAPL
```
对指定标的执行多信号融合分析，建议包含 `news_sentiment` 和 `sec_filings` 增强判断深度

## 配置

需要配合 `fin-agent-mcp-server` 使用，MCP 服务器提供数据层和记忆层。

## 信号权重说明

| 信号来源 | 权重 | 说明 |
|---------|------|------|
| 技术面   | 40%  | 价格/量/指标最客观 |
| 基本面   | 35%  | 财报/估值/盈利质量 |
| 新闻情绪 | ≤15% | 硬上限，防止过度依赖 |
| 宏观环境 | 10%  | 利率/政策/周期 |
